# Chrome Web Store 提出手順（1.0.11）

## 提出するファイル

| 入力欄 | ファイル |
| --- | --- |
| 拡張機能のアップロード | `dist/AmazonPrivacyBlur-webstore-1.0.11.zip` |
| ストアアイコン | `icons/icon128.png` |
| スクリーンショット | `store/screenshot-1.png`、`store/screenshot-2.png`（各1280×800） |
| 小さいプロモーション画像（任意） | `store/promo-440x280.png` |
| 掲載文 | `store/listing-ja.md` |

`webstore` ZIPはmanifest.jsonがZIP直下にある提出専用の形式です。`source` ZIPと通常の配布用ZIPは、ここにはアップロードしません。

スクリーンショットは架空データを使用したローカルのデモ画面です。ぼかしと設定画面には実際の同梱コードを使用し、画像内にもデモである旨を明記しています。Amazon実サイトの画面を撮影したものではありません。

## 先に行うこと

1. 更新ソースをGitHubにアップロードし、README・PRIVACY.mdを公開します。
2. https://github.com/QK777/amazon-privacy-blur/blob/main/PRIVACY.md がログアウト状態でも読めることを確認します。
3. GitHubリポジトリでIssuesを有効にし、サポート先を利用できるようにします。
4. Chrome Web Store開発者ダッシュボードで登録と登録料の支払いを済ませ、連絡先メールの確認を行います。
5. 普段使うChromeでこのバージョンを読み込み、ログイン済みAmazonの対象ページでぼかしを確認します。ローカルの自動テストは済んでいますが、実サイトの最終確認は別途必要です。

## プライバシー欄の入力原稿

### 単一の目的

Amazon.co.jpの注文履歴・注文詳細・住所帳などの名前・住所欄を登録なしで「*」表示またはぼかしで隠し、画面共有時の映り込みを軽減すること。ページ本文の郵便番号とユーザーが任意で指定した補助文字列もブラウザー内で処理します。

### storage権限の理由

ユーザーが指定した追加の文字列、オン／オフ、隠し方（「*」またはぼかし）をchrome.storage.localに保存し、ブラウザーを再起動した後も同じ設定を利用するために使用します。Chromeの同期用ストレージは使用せず、開発者へのデータ送信も行いません。

### Amazon.co.jpへのアクセスの理由

Amazon.co.jp内の対応する名前・住所欄を自動的にぼかし、ページ本文の郵便番号や補助文字列を検出するために必要です。対象ドメイン内のフレームにも対応します。他のサイトにはコンテンツスクリプトを読み込みません。

### リモートコード

「使用していない」を選択。JavaScriptとCSSはすべて提出ZIP内に同梱しています。外部コードの取得、eval、外部ライブラリーの実行はありません。開発用の画像生成・テストコードは提出ZIPに含めません。

「*」表示のパターンはCSSに埋め込んだ12×24ピクセルの静的PNGです。スクリプトや外部参照を含まず、外部への取得・通信はありません。元のフォントや文字幅は変更せず、マスク用フォントの作成・読み込みも行いません。通常設定はCSSだけで動作し、本文の郵便番号検索は任意でオンにする方式です。

### データの取り扱い

外部送信がなくても、ローカルで情報を処理・保存することは申告の対象です。「何も取り扱わない」と一括して申告しないでください。

現行実装に基づく申告案:

- 個人を特定できる情報: 氏名・郵便番号・住所・住所欄内の電話番号・対応するお届け先表示を、ぼかすためにブラウザー内で処理します。任意の補助文字列に氏名などが含まれる場合は、ユーザー指定の設定としてローカル保存します。
- ウェブサイトのコンテンツ: Amazon.co.jpのページ内テキストを、一致する文字列の検出のためにブラウザー内で処理します。ページ内容の履歴は保存せず、外部へ送信しません。

ダッシュボードの各項目の説明と現行コードを照らし合わせて、上記に対応する項目を申告してください。データの販売、目的に関係しない利用・転送、信用判定・貸付への利用は行わないため、それぞれの確認文に同意できます。

プライバシーポリシーURLにはlisting-ja.mdのURLを入力します。コードと掲載内容を変更した場合は、申告内容も合わせて更新してください。

## 審査担当者向けの説明

本拡張機能はAmazon.co.jpのページの表示だけを加工します。外部サービスへのアカウント登録や有料契約は不要です。Amazon上のログイン後の氏名・住所欄にはAmazonアカウントが必要ですが、追加登録した文字列と郵便番号形式の検出は公開の商品ページでも確認できます。

自動ぼかしの確認手順:
1. Amazon.co.jpで、上部のお届け先表示や、ログイン後の注文履歴・注文詳細・住所帳を開きます。
2. 対応する宛名・住所欄が、文字列を登録しなくても初期状態から「*」表示になることを確認します。
3. 注文履歴で住所ポップアップを開き、対応する住所部分も隠れることを確認します。
4. 商品名や注文金額などは、その形式が郵便番号に一致する場合を除いて表示されます。
5. ポップアップの「隠し方」でぼかしにも変更できることを確認します。
6. オン／オフを切り替え、元の表示に戻ることを確認します。元の本文・住所入力値は保持され、送信値を匿名化するものではありません。

Amazonの個人情報欄が利用できない場合、公開の商品ページで任意の補助機能も確認できます。ポップアップの「その他の文字列も隠す（任意）」を開き、商品名の一部を登録して保存すると一致する本文がぼかされます。登録欄を空にして保存すると、この補助設定だけを削除できます。自動ぼかしにはこの登録は不要です。

画面上に日本の郵便番号形式がある場合は、その文字列も検出します。氏名を任意の文章から自動判定する機能はありません。

## 公開範囲

友人への配布を主にする場合は「限定公開（Unlisted）」を選べます。URLを知っている人がインストールでき、ストア検索には掲載されません。限定公開でも審査は必要です。

アカウント情報、掲載文、画像、プライバシー欄を確認して審査へ提出します。審査の承認は保証されません。

## 再生成

Windows、Node.js 22以上、Chromeを使用します。

```powershell
node scripts/generate-css.cjs
node scripts/store-assets.cjs
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package.ps1
```

画像は公開用ソースにも含めます。利用者が画像を再生成する必要はありません。
