# Amazon 名前・住所ぼかし

Amazon.co.jpの注文履歴・注文詳細・住所帳などの名前・住所欄を、文字列の登録なしで画面上ぼかすChrome / Edge用の拡張機能です。画面共有やスクリーンショット撮影時の補助に使えます。

現在のバージョン: **1.0.6** / Manifest V3 / 外部ライブラリーなし

## できること

- 上部のアカウント名・お届け先をぼかす。
- 注文履歴の宛名と住所ポップアップ、注文詳細の配送先・請求先、住所帳の対応する名前・住所欄を初期状態から自動でぼかす。
- 住所欄は氏名・番地・建物名・郵便番号などをまとめてぼかす。
- ページ本文にある日本の郵便番号形式を検出する。
- 欄以外の文字も隠したい場合は、補助機能で任意の文字列を登録する。
- ポップアップからオン／オフを切り替える。

名前・住所欄はページの構造を示すIDやクラスなどに対応するCSSで隠します。対応欄には最初から適用され、新しく表示された住所ポップアップやクラス変更も追加のJavaScript走査なしで反映されます。本文の郵便番号・補助文字列の描画にはCSS Custom Highlight APIを使用し、文字の分割やラッパー要素の追加は行いません。

## インストール

PC版Chrome / Edge向けです。Chrome Web Storeには現在公開していないため、展開したフォルダーを読み込みます。

1. このリポジトリの **Releases** から `AmazonPrivacyBlur-1.0.6.zip` をダウンロードします。
2. ZIPを展開し、中の `AmazonPrivacyBlur` フォルダーを保存します。
3. Chromeは `chrome://extensions`、Edgeは `edge://extensions` を開きます。
4. 「デベロッパーモード」をオンにします。
5. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` の入ったフォルダーを選びます。
6. 開いているAmazon.co.jpのページを再読み込みします。

Releasesに配布用ZIPがない場合は、GitHubの「Code → Download ZIP」で取得したソースの展開先を読み込むこともできます。フォルダー名ではなく、`manifest.json` がある場所を選んでください。利用者にNode.jsやPowerShellの実行は不要です。

読み込み後も保存したフォルダーは削除・移動しないでください。

## 使い方

初期状態はオンです。拡張機能メニューから「Amazon 名前・住所ぼかし」を開くと切り替えられます。

**名前・住所欄の自動ぼかしに、文字列の登録は不要です。** インストール後にAmazonのページを再読み込みしてください。オン／オフは自動保存されます。

対応欄以外の任意の文字列も隠す場合だけ、「その他の文字列も隠す（任意）」を開いて画面と同じ表記を登録し、保存します。この補助設定を使わなくても、対応する名前・住所欄は自動でぼかされます。

詳しくは [使い方.txt](使い方.txt) を参照してください。

## プライバシーと権限

| 項目 | 用途 |
| --- | --- |
| `storage` 権限 | オン／オフと登録した文字列を `chrome.storage.local` に保存 |
| `https://*.amazon.co.jp/*` | Amazon.co.jp内の対応ページ・フレームで表示を加工 |

拡張機能自身による外部通信、解析ツール、広告、外部コードの読み込みはありません。登録した文字列はブラウザープロファイル内に保存し、拡張機能から外部へ送信しません。

## 制約

- **表示上のぼかしです。** 元データの削除、コピーや開発者ツールでの閲覧の防止には使えません。
- 名前・住所欄をページ構造から判定する方式です。任意の文章から個人名や住所の意味を判定するものではありません。
- 上部や商品ページのお届け先では、都市名もまとめてぼかします。
- 郵便番号と同じ形式の商品番号などもぼかすことがあります。
- 任意の入力欄、画像内の文字、Shadow DOM内、Amazon側の表示変更には対応できない場合があります。
- 読み込み途中の一瞬の表示も含め、すべての個人情報を隠す保証はありません。画面共有前に実際の画面を確認してください。
- ログイン済みAmazon実画面での最終確認は行っていません。

Amazonの公式製品ではなく、Amazonとは関係のない個人開発の拡張機能です。

## 更新・削除

更新時は保存したフォルダーを新しいファイルで置き換え、拡張機能の管理画面で再読み込みし、Amazonのページも再読み込みします。削除は同じ管理画面の「削除」から行います。

## 開発・検証

ビルド処理や依存パッケージのインストールなしで、リポジトリ直下を拡張機能として読み込めます。テストにはNode.js 22以上とインストール済みChromeが必要です。

```powershell
node --check content.js
node --check popup.js
node tests/content.test.cjs
```

テストは一時Chromeプロファイルとローカルの模擬ページを使います。普段のプロファイルやインストール済み拡張は変更せず、Amazonへのログインも不要です。Chromeが既定のWindowsパスにない場合は、実行ファイルを指定します。

```powershell
$env:APB_CHROME = 'C:\path\to\chrome.exe'
node tests/content.test.cjs
```

47項目の回帰テストには、名前未登録・JavaScript実行前の自動ぼかし、注文履歴・住所ポップアップ・配送先・請求先・住所帳・ネイティブ入力欄、商品名と金額の表示維持、ノードの追加・編集・削除・移動、設定変更、読み込み初期のオン／オフを含みます。5,000件の本文への1件追加は追加分の1件だけを走査し、対象外の1,000件の文字を含む領域の追加は文字ノードの走査0件です。オフ時はDOM監視を停止します。

自動ぼかしの対象を変更する場合は `scripts/generate-css.cjs` のセレクターを更新し、`node scripts/generate-css.cjs` でCSSを再生成します。生成結果の同期もテストで検証します。

これらは模擬ページでの検証結果であり、実AmazonでのCPU使用率や時間の削減率を示すものではありません。

## 配布ファイルの作成

Windows PowerShellでリポジトリ直下から実行します。バージョンは `manifest.json` から取得します。

```powershell
.\scripts\package.ps1
```

PowerShellの実行ポリシーで起動できない場合は、スクリプトの内容を確認した上で、そのプロセスだけを対象に実行できます。システムの設定は変更しません。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\package.ps1
```

`dist` に次のファイルを生成します。同じバージョンの生成済みファイルは上書きします。

| ファイル | 用途 |
| --- | --- |
| `AmazonPrivacyBlur-1.0.6.zip` | 利用者向け。拡張機能・使い方・MITライセンスを同梱 |
| `AmazonPrivacyBlur-source-1.0.6.zip` | GitHubへの手動アップロード用ソース一式 |
| `AmazonPrivacyBlur-webstore-1.0.6.zip` | Chrome Web Store提出用。manifest.jsonをZIP直下に配置 |
| `SHA256SUMS.txt` | 生成したZIPのSHA-256 |

生成スクリプトは必要なファイルだけを列挙してZIPに入れ、内容が元ファイルと一致することを検証します。ローカルの調査資料や別拡張は含めません。

## GitHubへの公開

**ブラウザーで手動アップロードする場合:** ソース用ZIPを展開し、`AmazonPrivacyBlur` フォルダーの中身を新しい空のリポジトリのルートへアップロードします。ZIP自体ではなく、中身のファイルを上げてください。`.gitignore` と `.gitattributes` も含めます。

**Gitで公開する場合:** このフォルダーでGitを初期化してコミットできます。`.gitignore` が生成ZIP・`dist`・ローカル調査資料・別拡張を除外します。初回コミット前には `git status` で公開対象を確認してください。

その後、GitHubでタグ `v1.0.6` のReleaseを作り、利用者向けZIPと `SHA256SUMS.txt` を添付します。DiscordにはReleaseのリンクを共有します。配布場所の変更だけでセキュリティ警告が解消する保証はありません。

問題報告にはブラウザーのバージョン、再現手順、警告があれば正確な文言を添えてください。氏名・住所・注文番号などは伏せてください。

## Chrome Web Storeへの提出

[提出手順とプライバシー申告原稿](store/submission-guide.md)、[掲載文](store/listing-ja.md)、[プライバシーポリシー](PRIVACY.md)を用意しています。アイコンと紹介画像も同梱しています。現在は提出準備の段階で、ストアでの公開・承認は済んでいません。

提出には開発者登録、GitHub上でのポリシーの公開、ログイン済みAmazonでの動作確認、審査が必要です。スクリーンショットは架空データを使ったデモ画面で、実際のぼかしコードと設定画面を使用しています。

画像を変更するときは `node scripts/store-assets.cjs` で再生成し、その後にパッケージ生成スクリプトを実行します。画像生成にはChromeを使用し、外部への通信は不要です。
